hashapass

command line password generator

Hashapass computes the HMAC-SHA1 of a parameter using your master password as the secret key, encodes the result in Base64, and takes the first 8 characters.

You can generate the exact same password from the command line using standard Unix tools: 

echo -n "$parameter" | openssl dgst -sha1 -binary -hmac "$password" | openssl enc -base64 | cut -c 1-8

Or as an interactive shell script:

#!/bin/bash
export IFS=""
read -rp "parameter: " PARAMETER
read -rsp "password: " PASSWORD
echo
echo -n "$PARAMETER" | openssl dgst -sha1 -binary -hmac "$PASSWORD" | openssl enc -base64 | cut -c 1-8
echo
