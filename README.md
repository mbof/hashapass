# Hashapass

A different password for every website and just one password to remember. Hashapass automatically generates strong passwords from a master password and a parameter (like the website or service name).

## Overview

Hashapass lets you remember just one password, and use it to generate a different password for every website or service. Given the same master password and parameter, Hashapass will always give you the same result.

- **Zero Server Storage**: Everything runs client-side in your browser. Passwords and inputs are never transmitted over the network or stored in any database.
- **Form Autocomplete**: Keeps browser parameter history functional so you can easily reuse previously entered site parameters.

---

## How It Works

The password is generated by calculating `HMAC-SHA1(key=masterPassword, data=parameter)`, encoding the resulting digest in standard Base64, and taking the first 8 characters.
